🚀 YouTube Tools – Spring Boot Full Stack Project

This is a full-stack web application built using Spring Boot that integrates with the YouTube Data API to fetch video details, tags, and related content.

The goal of this project is to practice real-world backend development and build a project that is strong enough to showcase in interviews and on a resume.

📚 What I Learned From This Project

How to set up and structure a Spring Boot project

Building REST APIs using Spring Boot

Integrating external APIs (YouTube Data API)

Handling JSON responses properly

Connecting frontend (HTML, CSS, Thymeleaf) with backend

Writing clean and structured code

Deploying a Spring Boot application

🛠 Tech Stack

Java

Spring Boot

Thymeleaf

HTML & CSS

Maven

✨ Features

Search YouTube videos

View video details

Display video tags

Copy all tags with one click

Clean and responsive UI

Optimized API calls

🔑 Environment Variable

To run this project, create an environment variable:

YOUTUBE_API_KEY=your_api_key_here

▶️ How to Run the Project Locally

Clone the repository:

git clone https://github.com/sejalpatildev/youtube-tools.git


Go to the project folder:

cd youtube-tools


Build the project:

mvn clean install


Run the application:

mvn spring-boot:run


Open in browser:
